# 🧩 ПромБезКроссворд

Интерактивные кроссворды по промышленной безопасности: ПБ, ПМЛА, АСФ, взрывопожаробезопасность, охрана труда.

**Ключевой принцип: правильные ответы никогда не покидают сервер.** Их нет в HTML, JS, JSON, LocalStorage и сетевых ответах студента. Все проверки и подсказки выполняются только в Netlify Functions.

## Структура

```
public/                                                  публикуемый сайт (только публичные файлы)
  index.html / generator.html / teacher.html / play.html страницы (чистые URL: /, /generator, /teacher, /play/:id)
  styles.css                                             стили (промышленная тема, mobile-first, print, тёмная тема)
  assets/*.js                                            клиентские скрипты (без фреймворков)
netlify/functions/_data/wordbank.js                      БАНК СЛОВ И ОТВЕТОВ — только на сервере
netlify/functions/_lib/engine.js                         движок построения сетки (серверный)
netlify/functions/_lib/store.js                          Netlify Blobs: кроссворды, счётчики
netlify/functions/_lib/validate.js, util.js              валидация, IP-хеш, токены
netlify/functions/*.js                                   API-функции
netlify.toml                                             редиректы, CSP и заголовки безопасности
```

Публикуется только `public/` — каталог `netlify/` статическому серверу недоступен, файл банка ответов нельзя скачать по прямой ссылке.

## API

Все ответы имеют `Cache-Control: no-store`. CORS — только свой домен.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/generate` | `{themes:[slug], count:5..20}` → `{id, skeleton, unplaced}`. Сетка строится на сервере. |
| POST | `/api/crossword` | Публикация кроссворда преподавателем. `{title, words:[{word,clue}|{clueId,clue}], settings}` → `{id, token, playUrl, manageUrl, skeleton}`. **Токен показывается один раз**, в БД — только SHA-256 хеш. |
| GET | `/api/crossword/:id` | Публичный скелет и вопросы, без букв. |
| POST | `/api/check` | `{id, sessionId, letters}` → вердикт **только по полностью заполненным словам** + общий счёт. Побуквенной подсветки нет. |
| POST | `/api/hint` | `{id, sessionId, letters}` → открывает одну букву. Лимит — настройка преподавателя (по умолчанию 3 на сессию). |
| GET/PUT/DELETE | `/api/crossword/:id/manage` | Только с заголовком `X-Manage-Token`. GET отдаёт полные данные с ответами. |
| GET | `/api/bank/:theme` | Вопросы банка для панели преподавателя (только вопросы; слова подставляются на сервере по `clueId`). |
| — | `sweep` (@daily) | Автоудаление кроссвордов без обращений 180 дней. |

## Защита ответов — что где проверяется

- Банк слов (`_data/wordbank.js`) живёт только в каталоге функций и не публикуется.
- Сетка строится в `engine.js` на сервере; клиент получает размеры, номера, направления, длины и вопросы.
- `/api/check` возвращает вердикт только целым словам; `/api/hint` — ровно одну букву за раз.
- Rate limit на подбор: проверка не чаще 1 раза в 3 с и не более 30/час на пару (IP-хеш, id). IP хранится только как соль-хеш (соль — переменная `PB_SALT`).
- Сравнение токенов — по хешам с постоянным временем (`safeEqualHex`).
- CSP без `unsafe-inline` (script-src/style-src 'self'), `X-Content-Type-Options`, `Referrer-Policy`, `frame-ancestors 'none'` — в `netlify.toml`.
- Печать студента (`@media print`) — пустая сетка с номерами и вопросами; буквы не выводятся.
- Ответы и токены не пишутся в логи (в логах только id и счётчики).

## Настройка и деплой на Netlify

1. **Репозиторий**: залейте папку проекта в Git-репозиторий и в Netlify выберите «Import from Git» (или перетащите папку в https://app.netlify.com/drop — работает без Git).
2. Настройки сборки подхватятся из `netlify.toml` (publish — корень, functions — `netlify/functions`). Зависимость `@netlify/blobs` устанавливается автоматически из `package.json`.
3. **Переменная окружения** (Site settings → Environment variables): `PB_SALT` — случайная строка для солирования IP-хешей (сгенерируйте, например, `openssl rand -hex 16`).
4. Netlify Blobs включён по умолчанию; отдельная настройка не требуется.
5. Проверьте после деплоя: откройте `/play/<id>` во вкладке Network — в ответах API нет букв ответов (кроме случая, когда преподаватель включил «Показывать ответы после завершения» и кроссворд решён).

Локальная разработка:

```bash
npm install
npm run dev     # netlify dev на http://localhost:8888
```

## Содержимое банка

Банк сгенерирован из предоставленного файла `crossword_words.xlsx`: 5 тем × 20 терминов (100 пар «слово–вопрос»). Для автогенерации сетки используются слова до 15 букв (51 слово) — ограничение из инструкции к банку; остальные доступны преподавателю через конструктор с ручным подбором. Полные данные — `netlify/functions/_data/wordbank.js`.

## Известные особенности

- Слово **ФЗ116** (тема ПБ) не помещается в автосгенерированные сетки: его буквы (Ф, З, 1, 6) не встречаются больше ни в одном слове темы. Генератор честно перечисляет его в `unplaced`; в готовых темах оно не участвует.
- QR-код для шеринга не встроен (CSP без внешних CDN); ссылка копируется кнопкой.
- Редактирование в панели преподавателя создаёт новую версию записи с той же секретной ссылкой.
